Iterative Pre-Order · Iterative Inorder · Sqrt(x)

1. Iterative Pre-Order Traversal2. Iterative Inorder Traversal3. Sqrt(x) (LC 69)
GoalVisit nodes in Root → Left → Right order without recursionVisit nodes in Left → Root → Right order without recursionReturn floor(√x) without using a built-in sqrt
LC equivalent1449469
Core ideaA stack simulates the recursion. Visit a node as soon as you pop it.Go as far left as possible, then visit the node, then move to its right subtree.Binary search on the answer. Find the largest m where m*m <= x.
Data structureStack of nodesStack of nodes plus a curr pointerTwo pointers, lo and hi
Steps 1. If the root is null, return.
2. Push the root.
3. While the stack is non-empty: pop, visit, push right child, then push left child.		 1. Set curr = root.
2. While curr or the stack is non-empty: push curr and go left until null.
3. Pop, visit, then set curr = popped.right.		 1. Set lo = 0, hi = x.
2. While lo <= hi: mid = lo + (hi - lo) / 2.
3. If mid <= x / mid, record ans = mid and set lo = mid + 1. Otherwise set hi = mid - 1.
4. Return ans.
TimeO(n)O(n)O(log x)
SpaceO(h), where h is the tree heightO(h)O(1)
Key trickPush right before left so left is popped first.The loop condition must be curr != null || !stack.empty().Compare mid <= x / mid instead of mid * mid <= x to avoid integer overflow.
Common mistakesPushing left before right gives the wrong order. Forgetting the null-root check.Using only while (!stack.empty()), which skips the start. Forgetting to move to right after the visit.Overflow on mid * mid. Returning hi or lo incorrectly. Not handling x = 0 and x = 1.
Edge casesEmpty tree, single node, skewed treeEmpty tree, left-skewed tree (stack grows to n)x = 0, x = 1, x = 2147483647, perfect squares
Useful to knowPreorder is used to copy or serialize a tree.Inorder on a BST gives sorted order, which is the basis for Kth Smallest in BST and Validate BST.Newton's method (r = (r + x/r) / 2) is an alternative that converges faster. The same pattern appears in "Search in Rotated Array" and "Find Peak Element".

Quick memory hook

  • Preorder: pop → visit → push R → push L
  • Inorder: go left, pop → visit, go right
  • Sqrt: binary search on the answer, comparing with division
